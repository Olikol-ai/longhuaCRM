# Группы (Group)

Группа — основной рабочий контекст администратора для групповых курсов.

## Назначение

- объединение учеников под одного преподавателя;
- настройка расписания курса (серия уроков);
- просмотр сгенерированных уроков;
- отметка посещаемости по каждому уроку.

## UI

| Маршрут | Описание |
|---------|----------|
| `/Groups` | Список групп |
| `/Groups/:groupId` | Карточка группы (вкладки: Обзор, Ученики, Расписание, Уроки) |

## API

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/groups` | Список групп |
| GET | `/api/groups/:id/workspace` | Группа + участники + серии + уроки |
| POST | `/api/groups/:id/members` | Добавить ученика |
| DELETE | `/api/groups/:id/members/:memberId` | Удалить ученика |

## Расписание курса

Создаётся через `POST /api/lesson-series` из карточки группы. Серия хранит слоты в `lesson_series_slots` (день недели + время). Генератор создаёт уроки с проверкой доступности преподавателя.

## Посещаемость

Отдельного раздела «Посещаемость» нет. Отметка — в карточке урока (вкладка «Уроки» группы или модальное окно урока в «Расписании»). API: `/api/lessons/attendance/*`.

## Связанные сущности

- `groups`, `group_members`
- `lesson_series`, `lesson_series_slots`
- `lessons`, `attendance_records`
